Smart Waste Management System (OOP + SOLID Principles)
Overview

This project is a simplified Smart Waste Management System developed in C++.
It demonstrates the application of Object-Oriented Programming (OOP) concepts together with the SOLID design principles to create a modular, maintainable, and extensible software architecture.
The system models the interaction between different users (Citizen, Driver, Technician, and Supervisor), smart waste bins, sensors, complaints, and route optimization.
